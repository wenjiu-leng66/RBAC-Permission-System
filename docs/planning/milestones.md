# 阶段范围

| 阶段 | 模型与实现 | 主要交付 |
| --- | --- | --- |
| 第一阶段 | RBAC0、面向功能后端 | 完整界面原型、统一 API、可运行的服务器后端、结构化设计、分层测试与覆盖率 |
| 第二阶段 | RBAC1、角色继承、面向对象后端 | 继承 DAG、两种后端的同契约实现及等价性测试 |
| 第三阶段 | 职责分离、基数、会话约束与审计 | 约束、角色激活、函数式模块、完整界面和最终材料 |

后续阶段须保持前序已验收功能。第一阶段当前实现不包含角色继承、SSD/DSD、基数、主动激活切换及审计；相关页面为静态原型。每次验收记录独立的源码版本与证据，日程以正式课程通知为准。
