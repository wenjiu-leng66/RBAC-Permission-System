# 数据字典草案

主责：成员 1。尚未冻结字段、建表或选择迁移工具。

| 概念 | 主要信息 | 重要关系与约束 |
| --- | --- | --- |
| 用户 | 内部 ID、用户名、姓名、部门、岗位、密码哈希、状态 | 用户名唯一；账号角色通过关系维护 |
| 部门 | ID、名称、上级、负责人用户 ID | 禁止上级循环；根节点允许无上级 |
| 角色 | ID、稳定角色码、名称、状态 | 同一用户可以有多个角色 |
| 资源与权限 | 系统、模块、功能、操作、稳定权限码 | 不使用显示名称作唯一程序判断依据 |
| 用户角色 | 用户与角色关联 | 组合唯一；分配时校验约束 |
| 角色权限 | 角色与权限关联及所需范围 | 组合、范围含义需统一 |
| 角色层级 | senior 与 junior 关系 | 方向明确；无环；多继承是否支持待确认 |
| 约束 | 类型、角色集合、参数、启用状态 | 区分分配、激活、请求时校验 |
| 会话 | 登录用户、已激活角色、失效信息 | 是否持久化以及如何撤销待确认 |

正式字典为每个字段补上类型、是否为空、默认值、唯一键、外键、来源和删除策略。不要在字典中填入真实密码或电话号码样例。
