# 界面原型说明

一期原型提供完整角色视角和操作状态，使用合成内存数据。真实后端以 Cookie/MySQL 独立运行，两者分别验收。构建与运行见[前端说明](../../frontend/README.md)。

## 页面范围

| 页面 | 路由 | 访问或检查要点 |
| --- | --- | --- |
| 登录、修改密码 | `/login`、`/password` | 通用登录失败提示、首次登录强制改密 |
| 门户、功能点 | `/portal`、`/portal/f/:fid` | 仅有 read 权限的菜单与功能点；六动作逐项显示范围 |
| 员工台账 | `/ledger` | 查看范围、仅电话/邮箱可编辑、范围外拒绝 |
| 我的权限 | `/me/permissions` | 代码、范围、来源角色、检索与空态 |
| 管理概览、用户 | `/admin`、`/admin/users` | 按范围筛选分页、用户维护、角色分配与保护规则 |
| 组织架构 | `/admin/departments` | 只读树、负责人、直接/含下级人数及成员范围 |
| 角色、角色授权 | `/admin/roles`、`/admin/grants` | 内置保护、权限树、read 前置、整组保存、失败保留草稿及 409 |
| 资源目录 | `/admin/catalog` | 只读目录、系统/模块/权限码筛选与分页 |
| 403、404 | `/403`、未匹配路由 | 未授权和未知路由分别处理，无重定向循环 |
| 后续静态页面 | `/admin/hierarchy`、`/admin/constraints`、`/session/roles`、`/admin/logs` | 继承、约束、角色激活、审计不计入一期后端完成度 |

## 合成身份

| 账号 | 角色及范围 |
| --- | --- |
| `admin` | 唯一超级管理员；内置 ADMIN 授权只读 |
| `SG000001` | 公司领导；管理后台只读 |
| `SG000011` | 部门经理；台账查看 ALL、编辑 DEPT |
| `SG000281` | 项目经理；编辑限本项目部 |
| `SG000013` | 普通员工；业务范围 SELF，无管理后台 |
| `DEMO000100` | 部门管理员；本部门子树管理，只能分配业务角色 |
| `DEMO000101` | 首次登录强制改密 |
| `DEMO000102` | 停用账号，登录拒绝 |
| `DEMO000103` | 无角色，可登录但没有业务菜单 |

以上为原型账号，密码 `123456`。真实后端口令由运行环境提供，原型身份切换不会改变后端会话。

## 交互规则

权限加载前默认拒绝。路由和菜单使用同一策略；按钮按动作权限置灰，目标记录再校验 `ALL/DEPT/SELF`。同码范围取最大值，不同动作互不扩大。

授权页面编辑本地草稿，保存时提交完整集合和读取时的版本。失败保留草稿，409 后重新加载当前版本；模拟失败/冲突开关仅用于原型检查，不是生产 API。加载、空结果、失败及重试分别呈现。

数据为合成组织与人员，刷新后重置业务内存状态。原型测试结果不替代服务器接口、数据库或权限安全验收。
