# 用例模板

每个重要用例复制以下结构，给出正常与失败分支。

## UC-XX：用例名称

| 字段 | 内容 |
| --- | --- |
| 参与者 | 谁发起 |
| 目标 | 操作后获得什么结果 |
| 前置条件 | 登录、角色、数据准备等 |
| 触发 | 按钮或接口调用 |
| 正常流程 | 按步骤描述系统与参与者的交互 |
| 异常流程 | 无权限、参数错误、约束冲突、数据不存在等 |
| 后置条件 | 成功状态与失败时的保持状态 |
| 相关规则 | 权限码、数据范围、约束 |
| 验证用例 | 测试编号与预期结果 |

先覆盖登录、查询用户、赋予和撤销角色、配置权限、配置继承、配置约束、激活角色、执行受保护操作。

不要把每个资源目录功能都机械复制成相同用例；先描述权限平台的操作，再定义代表性受保护业务。
