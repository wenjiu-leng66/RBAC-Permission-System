# 需求范围草案

状态：待老师与小组确认。主责：组长；所有成员参与。

## 目标

管理市政公司的员工、部门、角色、应用功能资源与授权关系，验证基础 RBAC、角色层级、约束及不同编程思路。

## 候选范围

- 用户登录、退出、查询与必要管理。
- 部门组织展示、角色、资源目录与权限配置。
- 用户角色分配和撤销，后端权限检查。
- 角色层级配置与有效权限计算。
- 静态、动态职责分离及老师指定的其他约束。
- 本人数据范围检查及少量代表性业务联调。
- 面向功能和面向对象实现对比，适当的函数式计算模块。

原权限清单覆盖多个业务系统，默认作为资源目录管理。是否需要实现各系统的完整业务，由老师确认。
